Robots are fine. Use them carefully.

Ignore Previous makes small, free tools for people who use AI agents (programs that carry out tasks on a computer for you). The code for each one is public, so anyone can read how it is built. Each tool says what it sends, where it runs and what it cannot do.

What's Allowed

whatsallowed

A free checker that reads the settings files of Claude Code, Codex and Cursor and flags risky ones. Each finding names the file, the line number and a code for the rule.

For example: a setting that downloads a script from the internet and runs it at once, a helper tool that fetches new code each time it starts, or a file of secrets, such as passwords, that the agent can read without asking.

Runs on your own computer. It does not send usage data back to us. A check of your settings, not a full security assessment.

npx whatsallowed

Unclank

unclank

Skills (add-ons) for Claude Code and Codex. They check work made with AI help for signs that nobody checked it. Before launch, they look for leftover defaults on a site or app, such as the starter icon and page title. They also look for flaws in quiz questions and problems on game store pages. Each check cites its sources.

Runs inside Claude Code or Codex, so the files it reads go to that app like any other request. It adds no tracking of its own.

/plugin marketplace add ignore-previous/unclank
/plugin install unclank@unclank

Clank Safely

a page, not a program

A plain page for setting up Claude Code or Codex so it can't do more than you meant. It starts with a check of what is allowed now, then explains three ways of working with the official setting names, and says which settings the tool enforces and which are only advice. Each fact about a setting links to its source or is marked Unverified.

Advice only. It changes nothing on your computer and does not make an agent safe on its own.
