How to run it

Won't: change your config, or tell you a setup is safe. A clean result means its rules found nothing in the files they read.

Command
npx whatsallowed
New to the terminal?
Paste into
A terminal: PowerShell on Windows, Terminal on macOS or Linux.
From
Your project's folder.
What it does
Reads your agents' settings files and lists what it found, like the "In your terminal" example. The first time, npx asks to download What's Allowed from npm: type y. Needs Node.js 20 or later.
Undo
Nothing to undo: it changes no files or settings. npm keeps the download in its cache. The one exception is whatsallowed baseline, which writes one file of its own, ~/.whatsallowed/baseline.json, and only when you run it.

Claude Code, Codex or Cursor

Open the agent in your project's folder and paste this.

Rules:

2. Before you run a command, show it to me and wait for my yes.
3. The command is: npx whatsallowed
   After I say yes, run exactly that in this project's folder. If it needs a change, such as a --yes flag, show me the new command and wait for my yes again.
4. Don't change any file or setting, even to fix a finding. Explain the fix and I'll decide.
5. Don't open or print .env files, keys or other secret files. If a finding points to one, give me the file name only.
6. When it's done, explain each finding in everyday words, and tell me what changed on my computer. It should be nothing except npm's download cache.

Unclank

How to install it

GitHub

Finds what AI missed on your launch page, quiz or game store page.

For anyone shipping one with Claude Code or Codex.

Examples and how to install it
  • Runs inside Claude Code or Codex
  • Sends only what that app already sends
  • Edits files only when you ask

For example: a browser tab still showing the default icon, quiz answers you can guess without reading, or a store page that breaks a platform's AI rules. Every item cites its sources.

Example: one finding on a sample project

README.md (made-up project, Tidepool)
14## Features1516- [Insert key features here]
Avoid D08-013README.md:16
Leftover template text in the README: "[Insert key features here]".
Fix: fill in or delete each placeholder.
17- Tide tables for nearby beaches

From running the unclank-launch steps on a made-up site with starter leftovers planted in it, shortened. The full report listed 8 hits.

Three skills

Launch page unclank-launch
Use it when you're about to ship, deploy, share or open-source a site, app or repo, or want a launch or polish check.
Quiz unclank-quiz
Use it when a quiz, test, exam or set of flashcards needs checking before you print, hand out or publish it.
Store page unclank-store
Use it when you're about to submit, publish, crowdfund or announce a game or creative project, or need a platform's AI-disclosure rules.

How to install it

Won't: add tracking.

Claude Code
/plugin marketplace add ignore-previous/unclank
New to the terminal?
Paste into
Claude Code, where you type your requests. To start it, type claude in a terminal.
From
Any folder.
What it does
Adds Unclank's listing (a plugin marketplace) to Claude Code. It installs nothing yet. Claude Code confirms it added the marketplace.
Undo
Type /plugin marketplace remove unclank. That also uninstalls Unclank if you installed it.
/plugin install unclank@unclank
Paste into
Claude Code, after the command above.
From
Any folder. Choose Install for you to use it in every project.
What it does
Shows what Unclank adds (three skills) and asks where to install it. Then it installs the skills and says whether to run /reload-plugins.
Undo
Type /plugin, open the Installed tab, pick Unclank and choose Uninstall.
Or ask Claude Code to install it

Rules:
1. Use only the official repo, https://github.com/ignore-previous/unclank. Don't install anything from anywhere else.
2. Before you run a command, show it to me and wait for my yes.
3. Install it with these two terminal commands:
