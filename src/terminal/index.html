New to the terminal?

A terminal is a window where you type commands instead of clicking. It looks bare, but it only does what the command says. This page covers what you need to run the commands on this site.

What it is Open one Safe habits Agents

What you're looking at

  1. Where you are. The folder the terminal is working in. Commands act on this folder unless they say otherwise. It looks different on each system: see Open one below.
  2. What you type. Type or paste a command here, then press Enter. Paste one line at a time: text with a line break in it can run straight away.
  3. What comes back. The command's answer. When it finishes, the "where you are" line comes back, ready for the next command.

Open one in your project folder

Most commands on this site need to run in your project's folder, the folder that holds the code or site you want to check. These are the ways we recommend to open a terminal there.

Windows

  1. Open File Explorer and go into your project folder.
  2. Windows 11: right-click an empty part of the folder and choose Open in Terminal.
    Windows 10: hold Shift, right-click an empty part of the folder and choose Open PowerShell window here.
  3. A window opens. The last line shows your folder, like this:

PS C:\Users\you\my-project>

The app is called PowerShell. Commands on this site work in it.

macOS

  1. Press Cmd + Space, type Terminal and press Return.
  2. Type cd and a space. Don't press Return yet.
  3. Drag your project folder from Finder into the Terminal window. Its path appears after cd. Now press Return.
  4. The last line ends with your folder's name, like this:

you@Mac my-project %

cd means "change directory": go into this folder.

Linux

  1. Open your file manager and go into your project folder.
  2. Right-click an empty part of the folder and choose Open in Terminal. If your file manager has no such option, press Ctrl + Alt + T (this works on many desktops, including Ubuntu), then type cd, a space and the folder's path, and press Enter.
  3. The last line ends with your folder's name, like this:

you@laptop:~/my-project$

cd means "change directory": go into this folder.

Safe habits

Read it first

A command can do anything you can do on your computer. We recommend running commands only from a source you trust, and reading each one before you press Enter.

Paste

  • Ctrl + V on Windows
  • Cmd + V on macOS
  • Ctrl + Shift + V in most Linux terminals

Stop

Ctrl + C usually stops the command that's running, on every system. In Windows Terminal, click in the window first so no text is selected, or it copies instead.

Closing the window stops it too.

Why coding agents run in a terminal

A coding agent is a program that reads and changes files and runs commands for you. You start it in your project folder and it works there. The terminal shows each step. You can see what it wants to run. Its settings decide what it may do without asking: Clank Safely explains them.

Rather not type commands?

The commands on our home page have an Ask your agent tab, with a prompt to paste into Claude Code, Codex or Cursor instead, and one for claude.ai or ChatGPT. Clank Safely has a prompt too.
