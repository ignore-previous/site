Worth checking (5)  Medium: risky in some set-ups, harmless in others.

  A secrets file in this project isn't blocked from the agent
    (Deny rule: a setting that stops your agent reading a file or running a command.)
    What this means: Claude Code can read this file without asking, and anything it reads can end up in a prompt, a log or a tool call.
    What you could do: Add "Read(./.env)" to permissions.deny in .claude/settings.json, or "Read(**/.env)" to cover every copy.
    Where: ./.env, line 1  Found: ./.env  Rule: DENY-001

  MCP server "browser" runs an unpinned package
    (MCP server: a helper program your agent can call to use other tools or services.)
    What this means: Each launch fetches whatever version is newest. If the package or its publisher account is compromised, the next start runs the new code with your agent's access.
    What you could do: Pin an exact version, for example npx demo-browser-mcp@1.2.3.
    Where: ./.mcp.json, line 4  Found: npx demo-browser-mcp  Rule: MCP-001

  MCP server "tickets" changed since the baseline
    (Baseline: a saved copy of your MCP server settings, used to spot later changes.)
    What this means: Its command, arguments, URL or environment differ from what you recorded, so it may now run different code or connect somewhere else.
    What you could do: Check the change (git log or diff the file). If you made it, re-record the baseline with --reset-baseline.
    Where: ./.mcp.json, line 10  Found: tickets  Rule: DRIFT-001

    What this means: "npx" can run arbitrary code, reach the network or delete files, so allowing it with any arguments is close to allowing every command.
